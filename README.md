# TechSupport

A technical support assistant implementation designed to help users diagnose and resolve software, hardware, network, account, and system configuration issues using Google Gemini.

## Features
- Context-aware troubleshooting
- Handles various issue categories (software, hardware, connectivity, etc.)
- Professional and empathetic tone
- Systematic diagnostic approach

## Requirements
- `pytest`
- `google-genai`
- `python-dotenv`

## Setup
1. Clone the repository.
2. Install the required dependencies: `pip install -r requirements.txt`
3. Create a `.env` file with your `GEMINI_API_KEY`.
4. Run the application: `python main.py`
